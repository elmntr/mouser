Switching profiles loads saved choices without sending them. Save captures all current button, DPI, lighting, polling and macro choices. Reset changes this local draft only.

What gets applied?

Apply profile sends button mapping, DPI, lighting, sleep/click response, polling, and any bound macros. It replaces those device settings. Uploads can fail partway. Imported profiles must use Mouser JSON; Windows binary profile files are not supported.

Profiles are saved locally, not read back from the mouse.
